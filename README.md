## Что делает система

Пациент с телефона за минуту отмечает самочувствие, приём таблеток и заполняет опросники.
Данные сразу попадают в карточку **его ведущего врача**. Система проверяет правила и, если нужно,
поднимает сигнал, подсказывает маршрут к психиатру и проверяет безопасность «Авиандра» по инструкции.
**Клинические решения принимает только врач.**

| Задача кейса | Как реализовано |
|---|---|
| 1. Стандартизированная оценка | PHQ-9, GAD-7 (валидированные русские версии), PHQ-2/GAD-2 еженедельно, C-SSRS (скрининг), AUDIT-C, HAM-A и CGI (врач) |
| 2. Рекомендации по терапии | Карточка «Авиандра» по инструкции: показания, дозировка, противопоказания, взаимодействия, «вне инструкции» — только решением врача |
| 3. Риски и нежелательные явления | Светофор безопасности, вопросы о побочных эффектах и признаках серотонинового синдрома, отчёт «Сообщить врачу» |
| 4. Мониторинг динамики | Графики шкал и дневника, ответ на лечение (−50% = ответ), сводка перед приёмом |
| 5. Самоотчёт пациента | Запись дня за минуту, кнопка «Мне сегодня хуже», «ответить на один вопрос», личная заметка |
| 6. Каналы коммуникации | Чат врач–пациент, линии помощи, близкие с согласия пациента, другие врачи пациента |
| 7. Приверженность | Дневник приёма, % за месяц, пропуски, «перестал/уменьшил дозу» с причиной |
| 8. Маршрутизация к психиатру | «Обязательно, экстренно / обязательно / желательно» с источниками, готовый текст направления, памятка пациенту, обратная связь «пациент дошёл» |

Обязательные условия: роли «Врач» и «Пациент» с раздельными правами; связь «врач–пациент» по коду приглашения;
никаких клинических действий без подтверждения врача (журнал решений); сценарии А–Г с «Авиандром»;
алертинг с эскалацией; визуально различимые «обязательно / желательно» и предупреждения безопасности;
только зарегистрированные в РФ показания и дозировки; источники у каждой рекомендации; 152-ФЗ и 323-ФЗ.

## Сигналы (алертинг)

Категории по таблице правил клинического психолога команды — различаются цветом, значком и подписью:

* **ЭКСТРЕННО** (красный): высокий риск по C-SSRS, передозировка, беременность на Авиандре, серотониновый синдром.
  Сразу в кабинет и вторым каналом; нет подтверждения 15 мин — повтор каждые 5 мин, через 30 мин — резервному врачу.
* **СРОЧНО** (оранжевый): мысли о смерти в PHQ-9 / словах пациента (пациенту сразу открывается C-SSRS), умеренный риск, мания, резкое ухудшение, почти не ест.
* **ВНИМАНИЕ** (жёлтый): не выходит из дома, пропуски таблеток, низкая приверженность, побочные эффекты, «Мне сегодня хуже».
* **БЕЗОПАСНОСТЬ** (фиолетовый): алкоголь или вещества без назначения на фоне Авиандра.

Антиспам: одно правило по пациенту не повторяется 72 ч, если не стало хуже; красные и мысли о смерти — всегда.
Несколько правил — одна карточка с перечнем. Врач может отметить «ложное срабатывание».

## Архитектура

```
Пациент (PWA, телефон) ─┐                     ┌─ Кабинет врача (компьютер и телефон)
                        ├─ Django 5 + PostgreSQL ─┤
                        │  web/        экраны    └─ alerts-worker: повторы, эскалация, «молчащие» пациенты
                        │  alerts/     сигналы и доставка (кабинет, почта, Telegram)
                        │  clinical/   правила, шкалы, препараты — YAML, без правки кода
                        │  extraction/ разбор выписок без внешних нейросетей
                        │  rules/      версии правил из админки с проверкой перед активацией
```

**Расширяемость без изменения ядра:** шкала = файл `clinical/data/scales/*.yaml`, препарат = `clinical/data/drugs/*.yaml`,
правила сигналов и маршрутизации — YAML или админка («Версии правил»: проверка фактов, категорий, источников и наличия
обязательных правил суицидального риска; откат на версию из репозитория одной кнопкой).

## Научная обоснованность

* PHQ-9 — Kroenke 2001; рус. валидация Золотарева 2023 (α = 0,89), DOI 10.17759/cpse.2023120406
* GAD-7 — Spitzer 2006; рус. валидация Золотарева 2023 (α = 0,93), DOI 10.17759/cpp.2023310402
* C-SSRS — Posner 2011; официальный русский перевод; скрининговая версия для самозаполнения
* AUDIT-C — ВОЗ (официальная русская версия AUDIT); HAM-A — Hamilton 1959, пороги Matza 2010; CGI — Guy 1976
* КР Минздрава: «Генерализованное тревожное расстройство» 2024 (ID 457), «Паническое расстройство» 2024 (ID 456),
  «Депрессивный эпизод, рекуррентное депрессивное расстройство» 2024 (ID 301); Приказ МЗ № 668н
* «Авиандр» — инструкция (ОХЛП), РУ ЛП-№(002445)-(РГ-RU) от 31.05.2023, ГРЛС
* Не используем: HADS и MMAS-8 (платные лицензии)

## Закон и безопасность данных

152-ФЗ (сведения о здоровье — отдельное согласие, хранение в РФ, журнал доступа к карточке), 323-ФЗ ст. 13
(врачебная тайна: близкие — только с согласия пациента), ст. 36.2 (телемедицина: новое лечение — после очного приёма),
Закон № 3185-1 (диагноз ставит психиатр, помощь добровольна). В мессенджер уходит только метка пациента без ФИО и
диагноза. Врач видит только своих пациентов; резервный — временно и только по эскалированному сигналу.
Разбор выписок — без внешних ИИ-сервисов.
